Calculette V1
Calculette v1 est un projet réalisé dans le cadre de mon apprentissage de PySide6.
C'est une interface graphique codée en PySide6 qui permet d’exécuter 4 types de calculs(l’Addition, la soustraction, la multiplication et la division). 
Elle assure aussi la gestion des erreurs comme la division par zéro(0) évitant ainsi tout bug.

🌐Technologies
•Python 3
•PySide6
